Teaching

I have been teaching since 2016. I make interactive applications so that students can see the mathematics move. They run in the browser, without installation, and can be projected in class.

Applications for my courses

  • MAP1006 Applied Mathematics I: damped mass-spring oscillator, also as a Desmos version (in French).
  • MPU1054 Analysis in One Real Variable II: Riemann and Darboux sums, pointwise and uniform convergence, rearranging a series.
