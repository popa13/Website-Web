    Tests de convergence

    Pour une série à termes positifs \(\sum x_n\), chaque terme \(x_n\) est l’aire d’un rectangle de largeur 1 et de hauteur \(x_n\). Les sommes partielles sont croissantes : la série converge si et seulement si l’aire totale est finie. Les premiers termes n’y changent rien ; seule compte la queue, l’aire à partir d’un rang \(N\). Les quatre tests reposent sur la même idée : comparer cette aire à celle d’une série dont on connaît la nature.

    • Comparaison : si \(0 \le x_n \le y_n\) pour \(n \ge N\), les rectangles dorés sont dans les rectangles verts. Si l’aire verte est finie, l’aire dorée aussi ; si l’aire dorée est infinie, l’aire verte aussi.
    • Comparaison par limite : si \(\frac{x_n}{y_n} \to r > 0\), alors \(\frac{r}{2} y_n < x_n < \frac{3r}{2} y_n\) à partir d’un rang \(N\) : les rectangles dorés restent dans un tube autour de \(r\,y_n\), et les deux aires sont finies ou infinies ensemble. Si \(r = 0\), seule la majoration reste.
    • Racine (Cauchy) : si \(x_n^{1/n} \to r < 1\), on choisit \(r_1\) entre \(r\) et 1 ; à partir d’un rang \(K\), \(x_n \le r_1^{\,n}\) : les rectangles sont sous ceux d’une série géométrique. Si \(r > 1\), \(x_n \ge 1\) à partir d’un rang : l’aire est infinie.
    • Quotient (d’Alembert, aussi appelé test du rapport) : si \(\frac{x_{n+1}}{x_n} \to r < 1\), avec \(r < r_1 < 1\), on a \(x_n \le x_K\, r_1^{\,n-K}\) pour \(n \ge K\) : encore une série géométrique. Si \(r > 1\), \(x_n \ge x_K > 0\) à partir d’un rang.
    • Si \(r = 1\), les tests de la racine et du quotient ne permettent pas de conclure : \(\sum \frac{1}{n}\) diverge, \(\sum \frac{1}{n^2}\) converge, et les deux donnent \(r = 1\).

    Les graphes

    • En haut : les rectangles de \(x_n\) (en or) et ceux de la série de comparaison (en vert). La ligne verticale marque le rang \(N\) (ou \(K\)) : glissez-la, ou cliquez sur un rectangle. Ce qui dépasse est en rouge.
    • Au milieu : la suite qui décide du test (\(\frac{x_n}{y_n}\), \(x_n^{1/n}\) ou \(\frac{x_{n+1}}{x_n}\)), avec sa limite \(r\). Glissez la ligne dorée \(r_1\), ou le bord de la bande.
    • En bas : les aires à partir de \(N\). « Additionner les aires » ajoute les rectangles un à un, puis de plus en plus vite : les deux aires restent finies, ou deviennent infinies, ensemble.

    Écrire le terme général

    En fonction de \(n\) : + - * / ^, parenthèses, sqrt, log (logarithme naturel, comme dans les notes ; aussi ln), exp ou e^, sin, cos, arctan, n!, pi. Le produit peut être sous-entendu et les parenthèses de log n sont facultatives : 2n, n(n+1), (log n)^(-n), n! e^(-n). La série commence au premier \(n \ge 1\) où le terme est défini (\(n = 2\) pour 1/(n log n)). Si des termes sont négatifs, on étudie \(\sum |x_n|\) (convergence absolue, sections 3.2 et 3.3).

    Les limites \(r\) et les rangs \(N\), \(K\) sont calculés numériquement : les termes sont évalués jusqu’à \(n \approx 10^7\), en logarithme, ce qui permet de suivre \(n!/n^n\) ou \(2^n/n!\) bien au-delà de \(n = 1000\). Une valeur reconnue (une fraction, \(e\), \(1/e\)…) est affichée exactement. La nature des séries de comparaison usuelles (\(p\)-séries, séries géométriques) est reconnue d’après le terme général.
