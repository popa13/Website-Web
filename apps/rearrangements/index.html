Réarranger une série

Un réarrangement de la série \(\sum x_n\) est une série \(\sum y_k\) qui contient les mêmes termes dans un autre ordre : \(y_k = x_{f(k)}\) pour une bijection \(f : \mathbb{N} \to \mathbb{N}\). Pour une somme finie, l’ordre ne compte pas. Pour une série, il peut tout changer.

  • Théorème de Riemann : si la série converge, mais pas absolument, on peut réordonner ses termes pour que le réarrangement converge vers n’importe quelle valeur \(c\) choisie d’avance (ou diverge).
  • Théorème de réarrangement : si la série converge absolument, tous ses réarrangements convergent, et vers la même valeur.

Choisir les termes

  • Dans la banque : cliquez sur un terme (en vert, les positifs ; en rouge, les négatifs). Il devient le prochain terme \(y_k\).
  • Sur le graphe : cliquez au-dessus du dernier point pour ajouter le prochain terme positif, au-dessous pour le prochain terme négatif. Un aperçu en pointillé montre le pas avant le clic.
  • Au clavier : ↑ prochain terme positif · ↓ prochain terme négatif · → premier terme inutilisé, dans l’ordre de la série · Retour arrière annuler · R recommencer.
  • Motif : par exemple 1 positif, puis 2 négatifs (le réarrangement des notes de cours, qui converge vers \(\tfrac{s}{2}\)). Pour la série harmonique alternée, le motif \(p\) positifs, \(q\) négatifs converge vers \(\log 2 + \tfrac{1}{2} \log \tfrac{p}{q}\).
  • Le réarrangement : sous le graphe, glissez un terme pour changer sa place ; × le retire. La ligne \(f(1), f(2), \ldots\) donne la bijection.

Le procédé de Riemann

  • Choisissez \(c\) (champ, curseur, ou ligne dorée à glisser sur le graphe), puis « Un pas » (Espace), « Lancer » (Entrée) ou « +100 ».
  • Les termes positifs sont pris dans l’ordre tant que la somme partielle est au plus \(c\), puis les termes négatifs tant qu’elle dépasse \(c\). Comme \(x_n \to 0\), les écarts à \(c\) tendent vers 0.
  • Essayez-le avec une série qui converge absolument : les termes positifs ne suffisent plus à atteindre n’importe quel \(c\).

Écrire le terme général

En fonction de \(n\) : + - * / ^, parenthèses, sqrt, ln (ou log), exp, sin, cos, tan, arctan, abs ou |…|, n!, pi, e. Le produit peut être sous-entendu : 2n, n(n+1). Exemples : (-1)^(n+1)/n, sin(n)/n, cos(n*pi/3)/n, (-1)^n/sqrt(n). La série commence à \(n = 1\).

Le diagnostic (convergence, valeur \(s\)) est numérique : il utilise \(2^{18}\) termes et peut se tromper pour une série qui converge ou diverge très lentement.
